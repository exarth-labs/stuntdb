# Architecture decision records

An ADR is a short note that records one significant design decision: what was decided, why, and what the trade-offs are. Six months from now, it answers the question "why is it built this way?"

- **One file per decision:** `NNNN-short-title.md`, numbered in order. Start from [0000-template.md](0000-template.md).
- **Accepted ADRs are not rewritten.** If a decision changes, write a new ADR that supersedes the old one, and mark the old one as superseded.
- **Status values:** `proposed`, `accepted`, `rejected`, `deprecated`, `superseded by ADR-NNNN`.

The format is a short version of [MADR](https://adr.github.io/madr/).
